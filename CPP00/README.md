## description
**CPP00** is the first module of CPP language in the 42 common core, in this module we learn to use the standard cpp lib and to quit our old habits we had in C


## instruction
first clone this repo
```bash
git clone https://github.com/Pucci17PinkerZ/CPP.git &&
cd CPP/CPP00
```

Every ex directory has is own makefile, feel free to explore!:

```bash
make
```
> The available Makefile rules are: `make`, `make clean`, `make fclean`, `make re`.
